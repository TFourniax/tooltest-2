# PM005b — cited feature observations across imported file relocations

Design gate, 2026-09-20. Base IdleProof242714f1, qualified Core6ea6fbb.
This extends the existing feature memory and consumes Core's qualified
`git-file-lineage-1` view. It is not a second Git parser or memory journal.

## Acceptance before implementation

- Preserve separate feature keys, learning scores, assertions and Proof authority.
  Derive only INFERRED links between source-bound historical feature observations.
- Capture an observation only when the existing canonical feature model binds its
  anchor file to a parsed extraction and an exact SHA256. Persist hashes and the
  bounded existing snapshot, never source bytes or additional prompt text.
- Reuse ordinary atomic IdleProof state writes. Keep eight distinct observations
  per feature, with explicit discarded count. Legacy memories remain readable;
  missing observations are unavailable, never backfilled from today's source.
  This is bounded retained history, not a complete lifetime history claim.
- An explicit read-only `feature-lineage --from KEY --to KEY` command queries
  Core once for the destination anchor. No new subprocess enters the hot hook.
  Match both recorded anchor hashes and paths to an admitted imported relocation.
  Bind every result to both observation IDs and Core event ID/hash/commit.
- Validate retained observation hashes and the complete bounded Core response;
  reject corruption, wrong path/schema/authority, duplicate JSON keys, invalid
  encoding, malformed counts, timeout, oversize or nonzero exit. A negative or
  incomplete view is not proof of no relation. Never merge keys automatically.
- Cap observations at8, each encoded observation at16KiB, response at512KiB,
  Core items100, result links32, process timeout3s. Expose omissions and coverage.
  A read-only `--list` index exposes up to100 locally retained feature keys.
  Views concern recorded observations, not current applicability or chronology
  of feature intent. No identity, learning-score or assertion transfer.
- Provide cited JSON plus FR/EN text; test actual installed Core and packed Node
  consumer in an isolated repository, immutable state/index and corruption.
- Keep full npm suite, package, quality/adversarial/corpus and existing actual
  consumer latency budgets. Fresh PR, review and exact-main gates remain required.

Full PM005 symbol identity, edited relocation, complete feature histories and
